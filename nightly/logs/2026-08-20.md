## JOB 2 — Link check, slice 00

### Method deviation — Stage 1 was skipped

`mcp__workspace__web_fetch` **rejected every URL** in the slice with:

> "URL not in provenance set. web_fetch can only retrieve URLs that appeared in a user message, a prior web_fetch result, or a WebSearch result."

URLs read from a file on disk do not enter the provenance set, and this is an unattended run so the URLs cannot be re-supplied by a human. Stage 1 was therefore impossible.

**Decision: ran Stage 2 (Chrome) against all 170 rows instead of only against candidates.** This is strictly higher quality than the two-stage design — the fetch screen was only ever a cheap pre-filter with a 53% false-flag rate, and every verdict below comes from a real browser render with the host/path assertion applied. It is slower, which is the only cost. If the provenance restriction is permanent, the design should probably be re-specified as browser-only.
