- **Budget/context statement:** I ran a large number of direct page fetches and a smaller number of targeted web searches for this region, consistent with the "prefer direct fetches" instruction. I did **not** run out of budget, but I was unable to render any Facebook or Instagram page through the fetch tool (every facebook.com/instagram.com URL returned an empty body) — this is a **tool limitation, not a research shortcut**, and it affects every "secondary-source-only" row in the roster above. Those rows are honestly flagged as not primary-verified rather than asserted as fact.

One of these two stored records should be removed or merged.

This is a clean NET-NEW addition, verified on the school's own page, and specifically resolves one of the addendum's named collision risks (Windsor NS vs. Windsor ON vs. Windsor England) in NS's favour.
- **Important finding #3 — two "known-gone" stubs (Stellarton BJJ, Yarmouth BJJ) are dead by DNS, and three other stubs (Team Fortitude, Shelburne BJJ NS, Atlantic BJJ, Cape Breton BJJ) had no stored URL at all.** Of these five/six problem stubs: Shelburne BJJ NS, Atlantic BJJ and Cape Breton BJJ appear to be genuinely fictitious/erroneous (no matching business found in two independent, purpose-built NS BJJ directories); Stellarton BJJ's domain is dead with no replacement found; Team Fortitude and Yarmouth BJJ appear to be real, ongoing schools whose only web presence is now Facebook.
